# 通用 Glide 喷气尾焰（DX9 / SM3）

`util.glide.writeAddon` 调用 `util.jetexhaust.exportExhaust`，GUI Glide 导出不再需要实验安装器。有 WT `volumetricAfterBurner` 配置时，按当前机型提取原生颜色渐变、喷口遮罩、噪声、热扰动及尺寸参数，部署本目录 Lua 和预编译 VCS。缺少资源、转换工具或转换失败会报错，不静默退回旧分层网格。

- 体积：24 顶点包围体 + 96 步像素着色器积分，替代旧 55,296 顶点分层绘制。
- 喷口：原生配置指定层数、mask/ramp 索引和位置；不硬编码 MiG/Sukhoi 的层数。
- 热扰动：原生 RG 位移纹理采样场景颜色。
- 本地导出到 `garrysmod/addons` 时，同时把 VCS 放到 `garrysmod/shaders/fxc`。只通过 Workshop 分发的加载行为未验证。
- EXE 旁必须保留 `res/jet_exhaust`；用户导出时不需要 ShaderCompile。

## 已验证（2026-11-06）

- 72 项 Python 回归通过，包括惯性换轴/尺度、参数图编码、资源缺失报错、无旧分层渲染器和静态炮口卡隐藏。
- 喷口光层从出口沿发动机内部排列；`test_nozzle_placement.lua` 验证零角度/旋转后的八层位置及熄火无几何。J-16侧后截图复查通过。
- `aces_weapon_fire` 非jet_flame材质使用 `$no_draw 1`，避免静态炮口卡成为翼下常亮碎片；实际开火闪光由运行时效果提供。此次未实现挂载武器。
- J-16 完整 GUI 导出流程成功（自动拆分机身/喷口，编译后 99/161 骨骼），安装到 `addons/wt_j_16`。
- GTerm：9 个体积 GPU 场景通过，侧视连续性约 0.783；熄火及整面墙遮挡均零发光。
- 喷口/热扰动 GPU 检查通过：亮环、暗心，修正内缩后白色 65/2301 亮像素；热扰动改变背景，关闭后不改变。
- J-16 喷口开合及斜后/侧/后方截图成功。截图：GMod `data/dae_j_16_{oblique,side,rear}.png`。

## 飞机惯性

通用飞机导出读取 FM 的 `MomentOfInertia`，WT Y-up 换到 Source Z-up，换轴 `(x,z,y)`；尺寸倍率为 `(40*0.0254)^2`，质量倍率为导出质量/原生空重。无有效原生惯性时保留模型惯性，不填诊断用包围盒值。燃油/载荷采用统一比例近似，未模拟其精确空间分布。

J-16 默认模型惯性与原生换算值的平地对照中，默认值出现交替偏航振荡；原生值约 `(86588,330610,393584)` 不再复现。正式生成实体三轮着地、无动力静止，直线全推力达到约 2404 units/s 时偏航约 0.004°。未修改悬挂或推力。初期测试点在平台边缘，缺轮接地的数据不可用于调悬挂。

## 限制

这是 WT 参数驱动的重建，不是原始 DXBC 逐条移植。噪声、激波与 Source LDR 曝光仍为近似；未完成体积穿入实体时的内部场景深度截断、WT HDR/大气后处理及热扰动软深度。不是所有 WT 字段都参与当前着色器。飞行操纵、多机 GPU 开销、不同机型与多人环境仍需验证。
